# Testing Copilot

This repository is designed for testing GitHub Copilot functionality and capabilities.

## Purpose

This project serves as a testing ground to evaluate and demonstrate various GitHub Copilot features, including:

- Code completion and suggestions
- Documentation generation
- Code refactoring assistance
- Bug detection and fixes
- Test case generation

## Hello World Greeting Cards

This repository now includes multiple implementations of "Hello World" greeting cards to demonstrate different programming approaches:

### 🌐 Web-based Greeting Card (`greeting-card.html`)
A beautiful, interactive HTML greeting card with:
- Animated CSS effects with glowing text and sparkles
- Interactive button with surprise message
- Responsive design with gradient backgrounds
- Modern styling with border effects

**Usage:** Open `greeting-card.html` in any web browser or serve it with a local HTTP server:
```bash
python3 -m http.server 8000
# Then visit: http://localhost:8000/greeting-card.html
```

### 🐍 Python Terminal Greeting Card (`greeting_card.py`)
A command-line greeting card generator with:
- Beautiful ASCII art borders
- Interactive menu system
- Animated text effects
- Custom message creation
- Date/time stamps

**Usage:**
```bash
python3 greeting_card.py
```

### 🟨 JavaScript/Node.js Greeting Card (`greeting-card.js`)
A Node.js terminal application featuring:
- Cross-platform terminal graphics
- Async/await interactive prompts
- Animated typing effects
- Custom card creation
- Graceful error handling

**Usage:**
```bash
node greeting-card.js
```

## Getting Started

This repository can be used to experiment with GitHub Copilot in various development scenarios. Feel free to:

1. Create new files and test Copilot's code suggestions
2. Write comments and let Copilot generate code
3. Refactor existing code with Copilot's assistance
4. Generate documentation and tests
5. Try the greeting card examples to see different programming approaches

## Examples of Copilot-Generated Code

The greeting card implementations demonstrate various Copilot capabilities:
- **HTML/CSS**: Modern web styling, animations, and interactive elements
- **Python**: Object-oriented design, CLI interfaces, and text formatting
- **JavaScript**: Async programming, Node.js APIs, and promise handling

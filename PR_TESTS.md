# PR Test Files

This directory contains test files designed to demonstrate GitHub Copilot functionality during pull request development and testing.

## Files

### `pr_test.js`
A JavaScript test file containing:
- Basic arithmetic functions (add, subtract, multiply, divide)
- Array utility functions
- String manipulation functions
- Error handling examples
- Simple test runner with assertions

**Usage:**
```bash
node pr_test.js
```

### `pr_test.py`
A Python test file featuring:
- Calculator class with type hints
- String utility operations (reverse, palindrome check)
- List utility functions (find max, find duplicates)
- Comprehensive unit tests using unittest framework
- Manual test demonstrations

**Usage:**
```bash
python3 pr_test.py
```

## GitHub Copilot Testing Scenarios

These files are designed to help test various GitHub Copilot capabilities:

1. **Code Completion**: Try adding new functions and let Copilot suggest implementations
2. **Test Generation**: Add new functions and ask Copilot to generate corresponding tests
3. **Bug Detection**: Introduce bugs and see if Copilot can identify them
4. **Documentation**: Add comments and let Copilot help generate documentation
5. **Refactoring**: Ask Copilot to help improve or refactor existing code
6. **Error Handling**: Extend error handling scenarios and test edge cases

## Example Copilot Prompts to Try

1. "Add a function to calculate the factorial of a number"
2. "Create tests for the factorial function"
3. "Add input validation to prevent negative numbers in factorial"
4. "Generate documentation for all functions"
5. "Refactor the calculator to use a class-based approach"
6. "Add more mathematical operations like power and square root"
